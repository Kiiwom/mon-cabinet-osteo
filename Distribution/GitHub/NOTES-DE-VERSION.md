# Mon Cabinet d’Ostéo 0.2.0 — essai

**Brouillon pour une future release.** Le dossier Distribution est en ligne ; aucune release n’est créée à cette étape.

Logiciel de cabinet local partagé gratuitement sous licence MIT. Cette préparation reste une version d’essai, en attente de validation personnelle par l’auteur.

Fonctions disponibles : dossiers patients, notes et consultations, préparation et émission de factures PDF, règlements, pièces jointes, exports de recettes et sauvegardes chiffrées. Le code comporte un outil d’import initial ; la migration complète et les parcours restants doivent être validés séparément.

Télécharger `MonCabinetOsteo-0.2.0-essai-Setup-x64.exe` pour Windows x64, et commencer par la démonstration. Python est inclus. Consulter `GUIDE-INSTALLATION.md` et les empreintes dans `SHA256SUMS.txt`.

Le code correspondant à cette distribution est disponible dans `Distribution/Sources/MonCabinetOsteo-0.2.0-sources.zip`. Les fichiers applicatifs lisibles à la racine du dépôt seront ajoutés séparément. La licence permet de lire, copier, modifier et redistribuer ce code, en conservant les notices.

L’installateur est non signé. Cette version ne revendique aucune certification du logiciel. Consulter `ETAT_IMPLEMENTATION.md` pour le périmètre initial et `Distribution/VERIFICATIONS.md` pour les vérifications de ce paquet. Ces documents ne remplacent pas les essais sur votre ordinateur.
