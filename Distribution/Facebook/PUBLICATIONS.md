## 1 — Annoncer le projet pendant les essais

Bonjour à toutes et à tous,

Je prépare un petit geste pour mes collègues ostéopathes : partager gratuitement le logiciel de cabinet que je développe pour mon propre usage, **Mon Cabinet d’Ostéo**.

L’idée est de disposer d’un outil local pour retrouver les dossiers patients, prendre les notes de consultation, préparer les factures et sauvegarder les données.

Je suis encore en phase d’essai. Un premier paquet de test est disponible sur GitHub avec l’installateur Windows, l’archive du code et les notices. Je terminerai mes vérifications avant d’annoncer sa diffusion pour un usage quotidien.

Le projet sera partagé sous licence MIT : chacun pourra lire le code, le copier, le modifier et le redistribuer en conservant la notice de licence.

Le projet et ses documents : https://github.com/Kiiwom/mon-cabinet-osteo/tree/main/Distribution . J’espère que ce travail pourra servir à d’autres cabinets et évoluer grâce aux retours de ceux qui auront envie de l’essayer.

## 2 — Annonce de disponibilité, après validation uniquement

Bonjour les collègues,

Comme promis, je vous partage gratuitement **Mon Cabinet d’Ostéo**, le logiciel que j’ai développé pour mon cabinet.

Il permet de gérer les dossiers patients, les notes de consultation, la préparation des factures et des PDF, le suivi des règlements et les sauvegardes chiffrées. Il fonctionne localement sur un ordinateur Windows 64 bits, avec une interface dans le navigateur, sans abonnement.
