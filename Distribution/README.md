## Contenu

- `Facebook/PUBLICATIONS.md` : trois brouillons avec les liens du dépôt, à adapter à la fin des essais.
- `Installateur/MonCabinetOsteo-0.2.0-essai-Setup-x64.exe` : installateur Windows autonome généré et testé, version d’essai.
- `Installateur/GUIDE-INSTALLATION.md` : installation, démonstration, emplacement des données et restauration.
- `Sources/MonCabinetOsteo-0.2.0-sources.zip` : code source sélectionné et scripts de construction, sans base de cabinet ni captures de travail.
- `Licences/LICENSE.txt` : licence MIT applicable au code original du projet.
- `Licences/DROITS-ET-STATUT.md` : explication en français des libertés et du statut des attestations.
- `Licences/Tiers/` et `Licences/DEPENDANCES.md` : notices et inventaire des composants embarqués.
- `GitHub/LIENS.md` : liens du dépôt, de l’installateur et de l’archive source.
- `GitHub/MISE-EN-LIGNE.md` : procédure pour publier le code et les téléchargements après validation.
- `Construction/` : scripts permettant de reconstruire la distribution.
- `VERIFICATIONS.md` : résultats réellement constatés lors de la préparation.
- `SHA256SUMS.txt` : empreintes de l’installateur et de l’archive source.

**Le dossier Distribution est publié sur GitHub à la demande de l’auteur ; aucune publication Facebook ni release GitHub n’est créée.** Les annonces de disponibilité restent à utiliser une fois vos essais terminés. Aucun certificat de signature numérique ou de conformité du logiciel n’a été émis.

Les fichiers `.exe` et `.zip` conservent leurs octets et leurs empreintes d’origine. L’archive représente l’instantané de construction ; ses documents décrivent donc la préparation initiale, antérieure à la création du dépôt. Les informations de publication à jour sont dans le présent dossier en ligne.
